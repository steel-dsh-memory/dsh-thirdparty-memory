# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short:

- Be respectful. Disagreement is fine; harassment, personal attacks, and
  discriminatory language are not.
- Assume good faith. Explain the problem, not the person.
- Respect privacy. Memory contents, personal paths, customer data and
  credentials must never appear in issues, pull requests or screenshots.
- Keep it on topic. This is a small, unofficial project; maintainers may close
  threads that turn into unrelated arguments.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and
when representing the project elsewhere.

## Enforcement

Report unacceptable behaviour privately through the repository's **Security →
Report a vulnerability** channel, or contact the maintainer listed in
`package.json`. Reports are handled confidentially. Consequences range from a
warning to a permanent ban, at the maintainer's discretion.
